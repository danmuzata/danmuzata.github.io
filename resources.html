In Development

Automated Homology Modelling

A wrapper around MODELLER that takes a target sequence (or a PDB ID to pull one from directly), finds and aligns suitable templates, and runs the modelling pipeline end to end — turning what's normally a multi-step manual process into a single automated run.

In Development

PDB Data Extraction

A utility for pulling structured information out of a PDB file in one shot — sequence, chains, ligands, resolution, and other header/coordinate metadata — without hand-parsing the file yourself.

In Development

Publication Figure Panels

A tool for assembling clean, publication-ready multi-panel figures (the kind journals expect for main and supplementary figures) from individual plots and structural renders, without the usual fight with layout software.
